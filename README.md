# Kindred Trails

A women-only trip organizing site: browse hosted tours, register or sign in, open a traveler portal, and complete a simulated payment.

This is a full working slice in the browser. Accounts and bookings are stored in `localStorage` on your device. Payment modes (card, UPI, net banking, wallet) are simulated — nothing is charged.

## Run locally

```bash
npm install
npm run dev -- --port 43147 --hostname 127.0.0.1
```

Open [http://127.0.0.1:43147](http://127.0.0.1:43147).

## What is included

- Home and tour catalog with itineraries, hosts, and inclusions
- Registration and sign-in
- Traveler portal (trips, receipts, profile)
- Checkout with four payment modes



## Stack
